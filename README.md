# Сайт Xlam Connect

1. Откройте `index.html`, найдите строку `const GITHUB = '';` и вставьте ссылку на репозиторий:
   `const GITHUB = 'https://github.com/username/xlam-connect';`
   Кнопки «Скачать» поведут на `/releases/latest`, «Исходный код» — на сам репозиторий.
2. Выложите папку на GitHub Pages: Settings → Pages → Deploy from a branch → `/ (root)` или `/docs`.
